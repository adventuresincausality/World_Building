## 🚀 How to Add a New Worldbuilding Example

1. Create a new directory under `projects/<your-new-project-name>/`.
2. Add your project's `index.html`, design specs (`.md` / `.docx`), and concept assets.
3. Update the master landing page (`index.html`) and this `README.md` with a new project card.

---

## 🌐 GitHub Pages Deployment

This repository is pre-configured for **GitHub Pages**:
1. Push this repository to GitHub: `git push -u origin main`.
2. Go to **Repository Settings** -> **Pages**.
3. Select `Branch: main`, `Folder: / (root)`, and click **Save**.
4. Your master portfolio hub will be live at `https://adventuresincausality.github.io/World_Building/`!
